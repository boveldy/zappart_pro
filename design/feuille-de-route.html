Feuille de route par couche

Toutes les fonctionnalités discutées, rangées par couche pour ne rien oublier. Zappart Pro = logiciel de gestion immobilière (web), avec la marketplace Zappart comme canal de diffusion.

Fait livré et déployé Suivant prochaine construction Planifié couche définie, pas commencé À décider dépend d'un choix

Principes verrouillés

  • Support — Zappart Pro est un outil de bureau. Sous 720 px, page « ouvrez sur ordinateur ». Le mobile reste l'espace partenaire de l'app (companion), non modifié pour l'instant.
  • Marketplace — publication sur Zappart uniquement, activable bien par bien. Aucune publication vers Airbnb / Booking. Seule ouverture externe : import iCal en lecture pour bloquer les dates déjà réservées ailleurs.
  • Services / prestataires — restent sur mobile. Hors périmètre de Zappart Pro. Un compte prestataire pur voit un simple encart.
  • Vente / achat — hors périmètre. Zappart = location (mensuel + journalier). La vente est un autre métier → phase 3 si décision produit.
  • Terrain — bons de visite signés, capture hors-ligne, signalement de panne par le locataire → mobile, pas le web.
  • Backend — 100 % Firebase pour la couche 1. Point de décision « ajouter un Postgres à côté » à la couche 2 (données relationnelles : baux, loyers, CRM, reporting).
  • Rôles — 2 seulement au lancement : gérant (tout) / agent (ses biens affectés). Pas de matrice de permissions.
  • Cible — agences mensuel et hôtes journalier, à parité.
  • Hébergement — GitHub Pages (build en CI). Plus tard : Firebase Hosting sur pro.zappart.xx.

Point de décision — base de données

  • La couche 2 est du relationnel (baux → échéances → paiements, agents → biens, contacts → leads → visites). Firestore le fait au prix de dénormalisation + triggers.
  • À évaluer alors : ajouter un Postgres (Supabase / Cloud SQL) à côté de Firebase — Firebase garde la marketplace / mobile / auth, Postgres porte la gestion.
  • On conçoit les collections couche 2 propres (clés étrangères claires, pas d'imbrication) pour garder la bascule possible. Jamais de migration complète.
